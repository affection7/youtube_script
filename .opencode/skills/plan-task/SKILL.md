# Планирование задачи

1. В начале задачи перечитай `AGENTS.md` и `PLAN.md`.
2. Не открывай `.env` и файлы `*.local.txt`.
3. Составь короткий план с разделами:
   - какие файлы будут изменены и зачем;
   - какие есть допущения;
   - как будет проверен результат.
4. Покажи план владельцу и дождись одного явного одобрения.
5. После одобрения не спрашивай разрешение продолжать и не делай дополнительных остановок, кроме случаев, разрешенных `AGENTS.md`.

Если задача требует изменения архитектуры, добавления зависимости, удаления данных или есть противоречие требований, остановись и задай вопрос владельцу.
