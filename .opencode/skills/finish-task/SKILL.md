# Завершение задачи

1. Запусти `python -m unittest -v`.
2. Запусти `python -m compileall -q .`.
3. Если любая проверка не проходит, исправь ошибку и повтори обе проверки.
4. Не открывай `.env` и файлы `*.local.txt`; не выводи секреты.
5. Обнови `PLAN.md` в разделах «Сделано», «Следующие шаги» и «Принятые решения», не создавая дубли.
6. Проверь `git diff` и перечисли измененные файлы с кратким назначением каждого.
7. Предложи сообщение коммита на английском языке.
8. Сам коммит не создавай, пока владелец явно не попросит его сделать.

Итоговый отчет должен содержать результат, проверки, измененные файлы и незакрытые вопросы.
