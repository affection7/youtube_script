# План и прогресс проекта

## Цель

Развивать Python-приложение для анализа YouTube-каналов, оценки их монетизации и генерации персонализированных Cold Outreach сообщений через DeepSeek.

## Сделано

- Изучены основные модули проекта, GUI, CLI, инструменты YouTube API и тесты.
- Исправлена передача и сохранение матрицы монетизации в отчетах.
- Исправлена блокировка GUI во время поиска каналов.
- Добавлены кэширование поиска и постраничная загрузка видео и комментариев.
- Улучшен разбор ссылок YouTube и расчет уверенности эвристического анализа.
- Ключи в GUI по умолчанию больше не сохраняются.
- Добавлены тесты для новых сценариев.
- Все 8 тестов пройдены, синтаксис Python-файлов проверен.
- Повторная проверка: все 8 тестов пройдены; добавлено исключение `.env` в `.gitignore`.
- Добавлена rule-based проверка Cold DM: длина, плейсхолдеры, шаблонные фразы и персонализация; добавлены тесты.
- Перенесена более новая версия с анализом внешних ссылок, риск-флагами, статистикой видео, приоритизацией комментариев, проверкой аргументов инструментов и расширенным GUI.
- После переноса: 36 тестов пройдены, синтаксис Python-файлов проверен.
- Полная rule-based проверка Cold DM восстановлена и подключена к сохранению отчетов; количество тестов увеличено до 37.
- Регрессии исправлены: восстановлены кэширование поиска и отклонение ссылок на видео; количество тестов увеличено до 39.
- Добавлены ограниченные retries с backoff для запросов DeepSeek и YouTube; количество тестов увеличено до 41.
- README синхронизирован с текущими возможностями, безопасным хранением ключей и запуском на Windows/Linux.

## Принятые решения

- Хранить постоянные правила работы в `AGENTS.md`, а межсессионный прогресс — в `PLAN.md`, чтобы не терять контекст между сессиями.
- Не менять архитектуру, структуру папок и зависимости без отдельного согласования с владельцем.
- Пока поддерживать только DeepSeek, но вынести LLM-провайдера за интерфейс для последующего добавления Gemini/NordRouter без переписывания основной логики.
- Минимальная версия Python — 3.11.
- Оставить читаемый отчет основным форматом и добавить JSON как дополнительный формат.
- Получать ключи только из переменных окружения или `.env`; не шифровать их, но не писать в логи и добавить `.env` в `.gitignore`.
- Считать production-готовностью проходящие тесты, конфигурацию из окружения, таймауты, ретраи и обработку ошибок API, логирование, README с инструкцией запуска и один сквозной прогон на реальных данных.
- Добавить rule-based проверку Cold DM по длине, незаполненным плейсхолдерам, шаблонным фразам и наличию персонализации; LLM-оценку пока не добавлять.
