## Цель

## Принятые решения

- Хранить постоянные правила работы в `AGENTS.md`, а межсессионный прогресс — в `PLAN.md`, чтобы не терять контекст между сессиями.
- Не менять архитектуру, структуру папок и зависимости без отдельного согласования с владельцем.
- Пока поддерживать только DeepSeek, но вынести LLM-провайдера за интерфейс для последующего добавления Gemini/NordRouter без переписывания основной логики.
- Минимальная версия Python — 3.11.
- Оставить читаемый отчет основным форматом и добавить JSON как дополнительный формат.
- Получать ключи из переменных окружения, `.env` или `*.local.txt`; не шифровать их, но не писать в логи и исключать все эти файлы из Git.
- Считать production-готовностью проходящие тесты, конфигурацию из окружения, таймауты, ретраи и обработку ошибок API, логирование, README с инструкцией запуска и один сквозной прогон на реальных данных.
- Добавить rule-based проверку Cold DM по длине, незаполненным плейсхолдерам, шаблонным фразам и наличию персонализации; LLM-оценку пока не добавлять.
- Не добавлять зависимости без отдельного одобрения; текущий процесс проверок остается на `unittest` и `compileall`.
- Для каждой задачи получать одно одобрение плана, затем выполнять согласованный план до конца без дополнительных остановок.

### Фактическое состояние перенесенной версии

- В агент добавлены анализ внешних ссылок, риск-флаги (`referral_farming`, `unverifiable_token_hype`, `leveraged_signals_promotion`), проверка аргументов инструментов, накопление состояния и обязательная проверка наличия предложения услуги в Cold DM.
- `tools.py` дополнительно собирает статистику видео, выбирает репрезентативные комментарии и учитывает внешние ссылки при расчете матрицы монетизации.
- GUI показывает полный отчет и Cold DM на отдельных вкладках, поддерживает копирование сообщения и фильтр каналов по диапазону подписчиков.
- `validate_cold_dm` проверяет длину, плейсхолдеры, шаблонные фразы и персонализацию перед сохранением сообщения; невалидный DM отклоняется.
- Поиск каналов кэшируется по нормализованному запросу и лимиту результатов; ссылки на видео в `parse_channel_input` явно отклоняются.
- GUI читает ключи из переменных окружения и не сохраняет их на диск; `.env` должен оставаться в `.gitignore`.
- Для временных сетевых ошибок DeepSeek и YouTube используются ограниченные retries с экспоненциальной задержкой; API-ключи в retry-ошибки не выводятся.
